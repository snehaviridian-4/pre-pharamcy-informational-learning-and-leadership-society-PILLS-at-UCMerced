# PILLS at UC Merced - Website

Welcome to the Pre-Pharmacy Informational Learning and Leadership Society (PILLS) website for UC Merced!

## About

This website provides information about our club, upcoming events, photo galleries, and ways to get involved with PILLS.

## Features

- **Home Page**: Welcome and featured information
- **About Us**: Learn about our mission and club information
- **Events**: View upcoming events and calendar
- **Gallery**: Photo gallery from past events
- **Contact**: Get in touch with us

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. No build process needed - just HTML/CSS!
